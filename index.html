NUBE GRATIS (FIREBASE) — TIEMPO REAL
Cómo obtener los datos (gratis, 5 min)
  1. Entra a console.firebase.google.com y crea un proyecto.
  2. Compilación → Realtime Database → Crear base de datos (modo bloqueado).
  3. En Reglas pon: {"rules":{".read":true,".write":true}} (solo tus datos de tareas).
  4. Configuración del proyecto → Tus apps → Web → copia apiKey, authDomain y databaseURL.
  5. Pégalos aquí en CADA dispositivo con el mismo Espacio (ej: casa).
